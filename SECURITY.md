# Security

## Reporting a vulnerability

Please email [security@neo.tax](mailto:security@neo.tax) with a description of the issue and steps to reproduce it. Don't open a public GitHub issue for security problems.

We'll acknowledge your report and keep you updated as we investigate and fix it.

## Supported versions

We fix security issues in the latest release. Installs move to a new release when the marketplace in this repository is updated to point at it.

## What the plugin sends

[PRIVACY.md](PRIVACY.md) lists every field the plugin can send, generated from the allowlist in the code. The [README](README.md#see-exactly-what-it-sends) shows how to run a local stand-in server and see exactly what leaves your machine.
